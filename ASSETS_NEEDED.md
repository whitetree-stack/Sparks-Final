# Assets Needed for Sparks of the Beacon

This document lists all assets that need to be created for the game to run properly.

## Background Images

Create these in `images/` folder (Ren'Py auto-detects by name):

| Filename | Used In | Description |
|----------|---------|-------------|
| `bg_library_ext.png` | Region 1 | Library exterior |
| `bg_library_int_new.png` | Region 1 | Library interior (new style) |
| `bg_library_int.png` | Region 1 | Library interior |
| `bg_valley.png` | Region 2 | Ironwood Valley |
| `bg_crystal_conservatory.png` | Region 3 | Crystal Conservatory |
| `bg_clocktower.png` | Region 4 | Celestial Clocktower |
| `bg_skybridge.png` | Region 5 | Eternal Skybridge |
| `bg_living_room.png` | Epilogue | Grandma's living room |
| `bg_act_2_start.png` | Act 2 | Act 2 opening |
| `bg_act_2_with_boys.png` | Act 1 | Transition scene |
| `bg_act_2_closeup.png` | Act 1 | Close-up transition |

## Notes

- All character images should be PNG with transparent backgrounds
- Recommended resolution: 1920x1080 or larger for backgrounds
- Character sprites typically work well at ~800px height
- The `rmbg` folder name suggests "removed background" - use transparent PNGs
